# رهنمای معاملات افغانستان

نسخه اولیه کامل پلتفرم «جستجوی آنلاین + دفتر معاملات حضوری».

## راه‌اندازی

1. یک Repository عمومی در GitHub بسازید.
2. تمام فایل‌های این پروژه را داخل Repository قرار دهید.
3. در Supabase یک Project بسازید.
4. محتوای `supabase/schema.sql` را در SQL Editor اجرا کنید.
5. در `assets/js/config.js` مقدارهای زیر را قرار دهید:
   - `SUPABASE_URL`
   - `SUPABASE_PUBLISHABLE_KEY`
6. فایل را Commit کنید.
7. GitHub Pages را برای branch اصلی و root فعال کنید.

GitHub Pages فایل‌های استاتیک را منتشر می‌کند؛ برای دیتابیس و Auth از Supabase استفاده شده است.

## نکات امنیتی

- Publishable key برای کد مرورگر است.
- Secret key / service key را هرگز در GitHub یا فایل‌های frontend قرار ندهید.
- RLS را در Supabase فعال نگه دارید.
- آدرس، شماره تماس و اطلاعات دفتر را قبل از انتشار واقعی تغییر دهید.
- متن قرارداد، احراز هویت، دریافت کمیسیون و فرآیند معامله باید با مقررات جاری افغانستان و رویه دفتر شما تطبیق داده شود.

## وضعیت

این repository یک پایه عملیاتی و قابل توسعه است. قبل از استفاده تجاری، سیاست‌های RLS، Storage، احراز هویت، فرآیند قرارداد و اطلاعات دفتر باید با داده‌های واقعی تست شوند.
